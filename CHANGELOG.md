# Changelog

Snake follows [semantic versioning](https://semver.org): a patch release fixes things, a
minor release adds something, and a major release changes file names or how it is placed
in a layout. The current number is in `VERSION`.

## 0.1.0 — 2026-11-20

First release, built on herdr-app 0.1.16.

- **Snake in a side panel**: a 16×16 board that fits the panel, arrows or WASD to steer,
  Space to start or pause, R to restart, faster with every dot, best score kept.
- **Pauses itself** when the panel hides or the keyboard goes elsewhere; no timer runs
  unless a game is running.
- **Its own Snake button** beside the tab bar, for Herdr's tab bar and Herdr Glass.
